# Day 01: Where Am I? Basic Orientation

**Phase 1 - File Navigation & Filesystem Mastery | Day 1 of 30**

## Commands covered today
See commands.md for the full list of 10 commands. I wrote each one in my own words and explained when I would use it.

## What I practiced
The drill had me moving from home to '/var/log' (absolute path), back home with '~', and then back to '/var/log' with 'cd -'. I listed '/var/log' in long, human‑readable format with 'ls -lh'. The whole point was to prove I could navigate without guessing.

## What surprised me
I thought 'cd -' would go home. It doesn’t. It flips between the last two directories. That’s actually more useful than I expected.
