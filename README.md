# Taymark-linux-command-mastery-challenge
**30 days. 300+ commands. Raw terminal logs. Public pressure-test.**

This repo is the unedited, commit-by-commit record of a deliberate sprint to move beyond surface-level Linux usage. The goal isn't just to memorize commands, it's to internalize the CLI as a primary interface for troubleshooting, automation, and systems introspection. By Day 30, this log proves I can navigate, manipulate, debug, and script across the entire userspace stack without reaching for a GUI crutch.
Every day's folder contains the exact commands I ran, the output they returned, and the break-fix notes for the ones that failed. What you see is what I typed—no post-hoc polishing.
